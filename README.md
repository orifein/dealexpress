# DEAL EXPRESS

אתר דילים בעברית (RTL) — Next.js 16 App Router, TypeScript, Tailwind.

מחיר **נחת בשקלים** הוא המחיר הראשי בכרטיס כשקיים `landedIls`.
העורך: **אורי**. קבוצת פייסבוק למעקב. טלגרם וואטסאפ ריקים.
אין מזהי שותפים מומצאים.

## פיתוח

```bash
npm install
npm run dev
npm run build
```

דילים אמיתיים ודוגמאות יושבים ב־`content/deals/`.
